# 🏁 beginners labs

> Tu punto de partida en el mundo de los CTFs. Si estás aquí es porque quieres aprender hacking desde cero, y esta es la mejor forma de hacerlo: **rompiendo cosas.** 💀

## ¿De qué va esto?

En esta sección vamos a resolver paso a paso la **playlist para principiantes** que ofrece [picoCTF](https://picoctf.org/) dentro de su plataforma. Es básicamente una guía guiada _(valga la redundancia)_ que te pone a prueba en las nociones más fundamentales de las distintas categorías que maneja la plataforma:

| Categoría              | ¿Qué aprenderás?                                              |
| ---------------------- | ------------------------------------------------------------- |
| 🔐 **Criptografía**    | Cifrados clásicos, encodings, conversiones de bases           |
| 💻 **Programación**    | Scripting básico con Python para automatizar soluciones       |
| 🛠️ **General Skills** | Manejo de terminal, comandos esenciales, protocolos básicos   |
| 🌐 **Networking**      | Conexiones remotas, transferencia de datos, protocolos de red |
| 🔍 **Forensics**       | Análisis de archivos, metadatos y datos ocultos               |

La idea es que vayas resolviendo cada reto a tu ritmo, entendiendo el **por qué** de cada paso y no solo copiando comandos como un robot. Aquí se viene a aprender. 🧠

## ¿No sabes por dónde empezar?

Tranqui, no pasa nada. Si sientes que aún te falta base para arrancar con los retos, picoCTF tiene una página de recursos **buenísima** donde te dan material de estudio gratuito para cada categoría:

🔗 [**picoCTF — Recursos de aprendizaje**](https://picoctf.org/resources.html)

Ahí vas a encontrar desde guías de Linux hasta tutoriales de criptografía y programación. Es todo lo que necesitas para prepararte antes de meterte de lleno con los retos.
